# Contribuir a GALA

Gracias por el interés. Antes de la primera contribución externa aceptada, el
proyecto activará un CLA (Contributor License Agreement) que cede al titular
del proyecto los derechos necesarios para el modelo de doble licencia
(AGPL-3.0 pública + licencias comerciales). Sin CLA firmado no se pueden
fusionar PRs. [Pendiente: texto del CLA + bot de gestión.]

## Normas
- Toda idea de funcionalidad nueva va a ISSUES-MVP2.md o a un issue, no a un PR
  directo: el alcance del MVP1 está cerrado.
- `gofmt` obligatorio; la CI rechaza código sin formatear.
- Los PRs incluyen tests de lo que tocan.
- Regla de hierro nº1 del README: ningún PR que incluya, enlace o facilite
  contenido/listas será aceptado, sin excepciones.
